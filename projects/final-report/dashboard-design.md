# Dashboard Design Direction (Confirmed 2026-06-25)

> 结论来源: 与产品经理讨论后确定，与店主反馈吻合。

---

## 核心原则

> **不是让店长在 AI Brain 面板里问，而是 AI 自动把结论推到 Dashboard。**

店长打开系统 → 5 秒内掌握店铺状况 → 有问题直接行动 → 不需要和聊天框对话。

---

## 设计方案

### 一屏概览 (Landing Page)

```
┌────────────────────────────────────────────┐
│  🏪  Bakery AI · 6月26日 (周五)             │
│                                              │
│  🚨 [警报 1] 面包椰丝剩 3 个 → 需补货       │
│      [警报 2] 今日无面包师排班 → 检查排班    │
│                                              │
│  ┌──────┬──────┬──────┬──────┐              │
│  │今天需求 │目前库存 │在岗员工 │昨日销售额 │
│  │ 146个  │ 210个 │ 5/6人  │ RM 580    │
│  │ ↑12%  │ 充足  │ 缺面包师│  ✓目标达成 │
│  └──────┴──────┴──────┴──────┘              │
│                                              │
│  [→ 预测详情] [→ 库存详情] [→ 排班] [→ 收入] │
└────────────────────────────────────────────┘
```

### 下钻页面 (Details)

保留现有 4 个面板的结构，但从概览屏点击图标进入，而不是从侧边栏切。

| 面板 | 内容 |
|------|------|
| 预测详情 | 7 天需求曲线 + 各产品预测 + 原因（含 AI 结论） |
| 库存详情 | 当前库存 + 鲜度 + 原材料 + 补货建议 |
| 排班 | 班表 + KPI + 签到状态 |
| 收入 | 日/周/月销售额 + 利润概览 |

## 对 S5 的影响

| 改动 | 影响范围 |
|------|----------|
| 新增 `/s5/dashboard/summary` → 返回结构化概览数据 | 🟢 新增接口，不破坏现有 |
| 现有 Agent 数据改为推送到 Dashboard 对应卡片 | 🟡 需修改输出通道 |
| AI Brain 聊天面板逐步淡出 | 🟢 仅前端隐藏，后端不动 |
| 警报系统 → 概览屏顶部展示 | 🟢 已有接口，只需前端适配 |

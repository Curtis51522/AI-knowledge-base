# Post-Demo Improvement Requirements

> Source: 2026-06-30 review session — identified gaps to reach commercial/industry grade
> Priority: High | Status: Triage needed

---

## 1. POS 收银界面完善

| 需求 | 当前状态 | 目标 |
|------|----------|------|
| 鲜度标注 | 英文 "Fresh" | 中文「刚出炉」/ BM "Baru Dibakar" |
| 收银流程 | 无找零功能 | 增加：Receipt 显示、Payment Method 选择（Cash/Card/QR）、输入实收金额、自动计算找零 |
| 小票 | 无 | 收银后生成可打印/显示的小票 |

## 2. Dashboard 信息聚合（老板视角）

### 核心原则
> 老板不想在 AI Brain 一个一个问，要一眼看完所有信息。

- [ ] 整合 S2 预测 → Dashboard 一块面板显示所有产品 7 天预测曲线
- [ ] 整合 S3 排班 → Dashboard 显示今日/本周人员安排概览
- [ ] 整合 S4 套餐推荐 → Dashboard 显示当前 Top-3 套餐 + 销售占比
- [ ] 整合 S5 AI Brain 决策结论 → Dashboard 直接显示各模块的 AI 建议（不用再问）

## 3. 数据展示与预测扩展

| 需求 | 说明 |
|------|------|
| 销售记录 | Dashboard 增加历史销售一览表（按产品/日期筛选）|
| 当前库存 | Dashboard 实时显示所有产品库存 + 鲜度状态 |
| 咖啡数据 | 增加咖啡品类单独的销售展示界面 |
| 产品原材料数据库 | 新增原材料表 + 界面展示库存 |
| 产量预测 | 不只是需求预测，还要预测「需要做多少」|
| 原材料购入预测 | 根据产量预测 → 推算需采购的原材料数量 |
| 所有预测附加原因 | 每个预测下方显示「为什么是这个数字」（关键词因素驱动）|

## 4. 员工管理完善

| 需求 | 说明 |
|------|------|
| **签到系统设计 (待实现)** | S3 Dashboard内嵌 | PIN码打卡，归入排班管理模块，不做在POS上 |
| 员工销售记录 | 每位员工经手的销售单记录 |
| 销冠统计 | 周/月/年维度统计（注：面包店可能不现实，需评估）|
| KPI 界面 | 完善现有 KPI 面板（出勤率、销售额、覆盖率等）|

## 5. AI Bundle Recommendation 改进

| 当前 | 目标 |
|------|------|
| 推荐搭配 + 折扣 | 推荐搭配 + **搭配原因**（口味互补/库存压力/新鲜度紧迫度）|
| Sales Script 生成 | 改为「搭配原因说明」，对店长展示而非对话术 |

## 6. AI Brain 界面转型

| 当前 | 目标 |
|------|------|
| 问答式输入输出 | 去掉独立问答界面，AI 分析结果直接嵌入 Dashboard 各对应模块 |
| 用户必须主动问 | 系统主动在 Dashboard 各区域显示 AI 分析的结论和原因 |
| 无解释 | 每个数字旁显示「为什么」（如：预测上升因为上周同期销量高 + 今天是周五）|

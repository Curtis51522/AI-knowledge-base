# DL-007: Final Formatting
> Status: pending | Project: DL (OCT Classification) | Priority: High | Created: 2026-06-11

## Goal
Apply APU paper formatting to the complete Word document.

## Requirements
- Font: Times New Roman 12pt throughout
- Line spacing: 1.5x
- Section headings: bold, appropriate hierarchy (Heading 1, Heading 2)
- Table formatting: consistent borders, centered, captions above
- Figure captions: below figures, centered, Figure 1/N style
- Page margins: APU standard (typically 2.54cm/1 inch all sides)
- Page numbers: bottom center
- References section: consistent citation format
- Title page: paper title, author, course code, date

## Constraints
- APU DL assignment format requirements
- Document must pass basic formatting check (no mixed fonts, consistent spacing)

# FR-001: Prepare Laptop & Deployment Environment for On-Site Bakery Testing

**Status:** pending
**Priority:** High
**Created:** 2026-06-12
**Depends on:** None

## Goal
Prepare a laptop with the complete Bakery AI System running and ready for on-site testing at the bakery.

## Requirements

### 1. Environment Setup
- [ ] Ensure Python 3.11+ and all dependencies from `requirements.txt` are installed
- [ ] Ensure MySQL is running and the `bakery_ai` database exists
- [ ] Verify both servers start cleanly:
  - Port 8002: `python main.py` (main server + frontend)
  - Port 8001: `python s5_agent/server.py` (AI Brain)
- [ ] Verify the frontend loads at `http://localhost:8002`
- [ ] Test login with manager account
- [ ] Verify all 5 panels load without errors (POS, Forecast, Schedule, Inventory, AI Brain)

### 2. Database Seeding
- [ ] Seed realistic initial inventory for all 6 products (e.g., 20-40 units each, mix of Fresh and Day-1)
- [ ] Ensure batch_inventory table has production_time values so freshness works correctly
- [ ] Create a test manager account and a test staff account
- [ ] Verify inventory panel shows correct batch data

### 3. Hardware Preparation
- [ ] Bring USB camera compatible with the laptop
- [ ] Test camera works with the POS scan feature (upload/scan a test image)
- [ ] Prepare a few actual bakery tray photos for demo if live camera is unavailable
- [ ] Ensure laptop battery lasts 2+ hours or bring charger

### 4. Pre-Test Smoke Check
- [ ] Run through the demo script (DEMO_SCRIPT.md) end-to-end
- [ ] Test EN/BM language toggle on every panel
- [ ] Test AI Brain with a Restock query and verify response
- [ ] Test AI Brain with a Waste query
- [ ] Confirm no JavaScript console errors on any panel
- [ ] Confirm S5 alerts system runs without connection errors

### 5. Contingency
- [ ] Note all credentials (MySQL, login accounts) in a secure local file
- [ ] Have backup of the codebase on USB or cloud
- [ ] Know how to restart servers if they crash

## Acceptance Criteria
- Both servers start without errors
- Login works for both manager and staff roles
- All 5 panels load and function
- AI Brain returns valid responses for Restock and Waste queries
- Camera scan accepts image upload
- Language toggle switches all panels correctly

## Notes
- The S5 server (:8001) must be started BEFORE or alongside the main server (:8002)
- If MILP solver errors appear, the system falls back to LP + rounding (acceptable)
- Real sales data will be collected during the field test for model retraining

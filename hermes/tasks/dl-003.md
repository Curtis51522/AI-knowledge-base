## Goal

## Requirements
### Dataset
- OCT2017_30K_V2: SHA256 global dedup process
- 237 cross-class duplicates removed + 7,324 intra-class duplicates removed
- Train: 24,972 (natural distribution), Test: 3,198 (800 per class, balanced)
- Train/Test zero overlap (SHA256 verified)
- Stratified split

### Models
- ConvNeXt-Base: 87.5M params
- Swin-Tiny: 27.5M params
- Both pretrained on ImageNet-1K

### Training Protocol
- Optimizer: AdamW
- LR schedule: CosineAnnealingLR
- Mixed precision: AMP
- EarlyStopping: patience=5
- Class weights: balanced
- EMA: 0.9999
- Swin-Tiny specific: warmup=3 epochs + grad_clip_norm=5.0
- Grid Search: 3 lr × 2 bs = 6 combos × 2 models, seed=99

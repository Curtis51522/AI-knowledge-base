# 学术英语论文常见表达速查

> 这是你读 AI/ML 论文时的私人翻译器。每次遇到不认识的句式，回来查。

---

## 一、论文各章节的常见句式

### Abstract（摘要）

| 英文惯用表达 | 中文意思 | 例句 |
|------------|---------|------|
| We propose a new ... | 我们提出了一种新的... | *We propose a new simple network architecture, the Transformer* |
| The dominant/models are based on... | 主流模型建立在...之上 | *The dominant sequence transduction models are based on complex recurrent...* |
| Experiments show that... | 实验表明... | *Experiments on two tasks show these models to be superior in quality* |
| Our model achieves... improving over the best results by... | 我们的模型达到了...超过最优结果... | *Our model achieves 28.4 BLEU... improving over the existing best results by over 2 BLEU* |
| Unlike prior work, we... | 与之前的工作不同，我们... | *Unlike prior work that uses RNNs, we rely entirely on attention* |
| We demonstrate that... | 我们证明了... | *We show that the Transformer generalizes well to other tasks* |

### Introduction（引言）

| 英文惯用表达                                 | 中文意思           | 用法                    |
| -------------------------------------- | -------------- | --------------------- |
| ... have been firmly established as... | ...已经被牢固确立为... | 描述已有技术/方法的地位          |
| Numerous efforts have...               | 许多研究尝试了...     | 列举前人的工作               |
| However, ...                           | 然而...          | **转折！这里通常引出论文要解决的问题** |
| This inherently ... precludes ...      | 这天然地阻止了...     | 描述旧方法的根深蒂固的问题         |
| The fundamental constraint remains.    | 根本的限制仍然存在。     | 强调旧方法无法被修补            |
| To this end, we propose...             | 为此，我们提出了...    | **引出本文贡献的关键句式**       |

### Method（方法）

| 英文惯用表达 | 中文意思 | 例子 |
|------------|---------|------|
| An attention function can be described as... | 注意力函数可以描述为... | 定义核心概念 |
| In our model, we use... | 在我们的模型中，我们使用... | 说明具体做法 |
| The input consists of... | 输入由...组成 | 描述数据格式 |
| We then apply... | 然后我们应用... | 描述处理步骤 |
| Specifically, ... | 具体来说... | 展开细节 |
| In contrast to... / Unlike... / Rather than... | 与...不同 / 不同于... / 而不是... | 强调与已有方法的区别 |
| Whereas ..., our approach ... | 而..., 我们的方法... | 对比不同方案 |

### Results & Discussion（结果与讨论）

| 英文惯用表达 | 中文意思 |
|------------|---------|
| As shown in Table X... | 如表 X 所示... |
| Figure X illustrates... | 图 X 展示了... |
| This suggests that... | 这表明... |
| We observe that... | 我们观察到... |
| It is worth noting that... | 值得注意的是... |
| A possible explanation is... | 一个可能的解释是... |
| One limitation is... | 一个局限是... |

### Conclusion（结论）

| 英文惯用表达 | 中文意思 |
|------------|---------|
| In this paper, we have presented... | 本文中，我们提出了... |
| Our results demonstrate... | 我们的结果表明... |
| Future work could explore... | 未来工作可以探索... |

## 二、高频连接词（无上下文容易卡住）

| 英文 | 中文 | 用法 |
|-----|------|------|
| **dispensing with** | 抛弃、省去 | *...dispensing with recurrence and convolutions entirely* → 完全抛弃了循环和卷积 |
| **solely** | 仅仅、完全 | *based solely on attention mechanisms* → 完全基于注意力机制 |
| **lend itself to** | 适合、有助于 | *self-attention could lend itself to...* → 自注意力有助于... |
| **incur** | 招致、带来（成本/损失） | *incurring prohibitive computational cost* → 带来极高的计算成本 |
| **preclude** | 排除、阻碍、使...不可能 | *This precludes parallelization* → 这阻止了并行化 |
| **mitigate** | 减轻、缓解 | *mitigate the issue of...* → 缓解...的问题 |
| **render** | 使得、导致 | *rendering them ineffective* → 使它们失效 |
| **facilitate** | 促进、方便 | *facilitate faster training* → 加快训练 |
| **adversely** | 不利地 | *adversely affects performance* → 对性能产生不利影响 |
| **yield** | 产生、得到 | *yields better results* → 产生更好的结果 |
| **retain** | 保留、保持 | *retain the original information* → 保留原有信息 |
| **foster** | 培养、促进 | *foster better generalization* → 促进更好的泛化 |
| **compelling** | 有说服力的、强大的 | *compelling sequence modeling* → 强大的序列建模 |
| **prominent** | 突出的、显著的 | *a prominent approach* → 一个突出的方法 |
| **notably** | 特别是、值得注意的是 | *Most notably, ...* → 最值得注意的是... |
| **to this end** | 为此 | *To this end, we propose...* → 为此，我们提出...（引论文动机） |
| **in terms of** | 在...方面 | *superior in terms of quality* → 在质量方面更优 |
| **ablation** | 消融实验 | 删除某组件后看效果变化的实验 |

## 三、AI/ML 论文特有的技术动词

| 英文 | 中文 | 场景 |
|-----|------|------|
| **encode / decode** | 编码 / 解码 | Transformer 核心操作 |
| **attend to** | 注意到、关注到 | *The model attends to all positions* → 模型关注所有位置 |
| **propagate** | 传播 | *backpropagate* → 反向传播 |
| **fine-tune** | 微调 | 拿预训练模型在小数据集上调 |
| **pretrain** | 预训练 | 在大数据集上先训练一个基础模型 |
| **generalize** | 泛化 | 模型在未见过数据上的表现 |
| **overfit** | 过拟合 | 训练集上很好、测试集上很差 |
| **converge** | 收敛 | 模型训练到损失不再下降 |
| **outperform** | 超过、优于 | *Transformer outperforms all baselines* |
| **benchmark** | 基准测试（n.）/ 与基准对比（v.） | |

## 四、让你立刻不卡壳的小技巧

### 「看不懂的句子」分解法

```
原文：The dominant sequence transduction models are based on
      complex recurrent or convolutional neural networks that
      include an encoder and a decoder.

拆解：
  主语：The dominant models → 主流模型
  修饰(什么样的模型)：sequence transduction → 序列转换（翻译）
  谓语：are based on → 建立在...之上
  宾语：complex recurrent or convolutional neural networks → 复杂的RNN或CNN
  定语(修饰networks)：that include an encoder and a decoder → 包含编码器和解码器的

整句：主流的序列转换模型建立在复杂的RNN或CNN之上，这些网络包含编码器和解码器。
```

### 识别「废话段」

```
看到 These have been shown to be effective in... → 跳
看到 Numerous works have explored... → 跳
看到 For a comprehensive survey, see... → 跳
看到 We refer the reader to... → 跳

读到 However, → 停！从这里开始仔细看
读到 To address this, → 停！论文的贡献要出现了
```

## 五、用 Transformer 论文原文做练习

打开 https://arxiv.org/html/1706.03762v7，Section 1 的第一段：

> **原文**：Recurrent neural networks, long short-term memory and gated recurrent neural networks in particular, have been firmly established as state of the art approaches in sequence modeling and transduction problems such as language modeling and machine translation.

> **逐词拆解**：
> - *have been firmly established as* = 已经被牢固确立为
> - *state of the art* = SOTA = 目前最高水平
> - *sequence modeling* = 序列建模（处理顺序数据的任务）
> - *transduction problems* = 转换问题（把一串东西变成另一串，如翻译）
>
> **整句**：RNN / LSTM / GRU 这类模型，已经被公认是序列建模和序列转换任务（比如语言建模、机器翻译）的最高水平方法。
